| Term | Explanation |
| --- | --- |
| ACC | Active Cell Count. The ACC cartridge measures metabolically active cells using an enzymatic assay. ACC is the total number of active cells inside the ACC gate. |
| CBC | Coliform Cell Count. Number of coliform cells counted in the sample. |
| Cartridge | Refillable container of reagents needed for BactoSense<br/>operation |
| EBC | E. coli Cell Count. Number of E. coli cells counted in the sample. |
| FCS | Flow Cytometry Standard (FCS) is a data file standard for<br/>the reading and writing of data from flow cytometry<br/>experiments. The FCS specification has traditionally been<br/>developed and maintained by the International Society for<br/>Advancement of Cytometry (ISAC). FCS used to be the<br/>only widely adopted file format in flow cytometry. |
| FL1 | Fluorescence signal 1 (530 nm) |
| FL2 | Fluorescence signal 2 (715 nm) |
| FSC | Forward scatter, also known as Small Angle Light<br/>Scattering. A detector measures the light scattered from<br/>microorganisms and other particles at small angles. |
| Gate | Gates are tools for data analysis of a subset of data points<br/>in flow cytometry. |
| HNA | High Nucleic Acid. Bacteria with a large amount of DNA<br/>which produce a strong fluorescence emission. |
| HNAC | High Nucleic Acid Count. The number of HNA bacteria<br/>inside the TCC or ICC gate, and above the HNA / LNA<br/>limit. |
| HNAP [%] | High Nucleic Acid Percentage.<br/>The percentage of HNA bacteria relative to the cell count. |
| ICC | Intact Cell Count. Total number of intact bacteria inside of<br/>the ICC gate. |
| LNA | Low Nucleic Acid. Bacteria with a lower amount of DNA<br/>which produce a weaker fluorescence emission than HNA<br/>bacteria. |
| LNAC | Low Nucleic Acid Count. The number of LNA bacteria<br/>inside the TCC or ICC gate below the HNA / LNA limit. |
| Manual Sampling Device | Connection module, allowing manual sampling with the<br/>BactoSense Online. |
| NBC | Enterococcus Cell Count. Number of Enterococcus cells counted in the sample. |
| Online Sampling Device | Connection module to a water line, allowing online<br/>sampling with the BactoSense Online. |
| SSC | Side scatter, also known as Large Angle Light Scattering. A<br/>detector measures the light scattered from<br/>microorganisms and other particles at 90 degrees. |
| TCC | Total Cell Count. Total number of bacteria detected inside<br/>the TCC gate. |
