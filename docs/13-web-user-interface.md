## 13.1 General information {#section-13-1}

- The web interface allows users to browse and export results and other data from a remote computer, as well as monitor the state of the instrument (active process, cartridge level, alerts etc.)
- The BactoSense needs to be connected to the same network as the computer that accesses the web interface.
- The web interface can be loaded on any browser on desktop computers or mobile devices.
- Take care about data and network security with all usual measures.

## 13.5 Download a zip file with multiple results {#section-13-5}

The results from multiple measurements can be downloaded as a zip file. This zip includes the FCS file and summary plots of each measurement.

|  | WORK STEP | ADDITIONAL INFO / IMAGES |
| --- | --- | --- |
| 1. | On the web interface, select the Results page on the navigation panel on the left. |  |
| 2. | Find the results for the mode you are interested in: Online mode or Manual mode results. |  |
| 3. | Select the date range you want and click Download ZIP. A progress bar will appear at the top of the browser until the zip starts downloading. | <img src="/img/manual/cell-836f089084c0.png" alt="Illustration for table on manual page 121" width="282" className="manual-figure" loading="lazy"/> |
| 4. | Wait for the download to complete. |  |

## 13.6 Download all results as CSV, XLSX or PDF {#section-13-6}

The list of all results can be downloaded from the web interface in either Excel XLSX, CSV or PDF format. The Online mode (Auto) results are separated from Manual mode results.

|  | WORK STEP | ADDITIONAL INFO / IMAGES |
| --- | --- | --- |
| 1. | On the web interface, select the Results page on the navigation panel on the left. |  |
| 2. | Find the DOWNLOAD RESULTS section, just below the top PLOT section. |  |
| 3. | Click on the desired file (xlsx, csv or PDF) to start the download. | <img src="/img/manual/cell-9979275487c3.png" alt="Illustration for table on manual page 121" width="282" className="manual-figure" loading="lazy"/> |
| 4. | Wait for the download to complete. |  |

## 13.7 Animate the evolution of dot plots {#section-13-7}

The web interface can animate dot plots from Online (Auto) mode, to help visualize the progression of the measurements. This feature shows static images in rapid succession; the animation can be exported with the Download GIF button.

|  | WORK STEP | ADDITIONAL INFO / IMAGES |
| --- | --- | --- |
| 1. | On the web interface, select the Plots page on the navigation panel on the left. | <img src="/img/manual/cell-0615055418e0.png" alt="Illustration for table on manual page 122" width="283" className="manual-figure" loading="lazy"/> |
| 2. | Use the previous and next arrows or the slider to centre the slider on the desired date range. | <img src="/img/manual/cell-fec791f8e8fd.png" alt="Illustration for table on manual page 122" width="283" className="manual-figure" loading="lazy"/> |
| 3. | Press the Play button to start the animation. | <img src="/img/manual/cell-fb7fd241751c.png" alt="Illustration for table on manual page 122" width="283" className="manual-figure" loading="lazy"/> |
| 4. | Adjust the animation speed if needed using the animation speed field. |  |
| 5. | The animation can be downloaded as GIF file when pressing the Download GIF button. |  |

## 13.10 Reboot from web user interface {#section-13-10}

The BactoSense can be rebooted from the web interface according to the following procedure.

:::info[Remote power-on is unavailable]

The instrument cannot switch on remotely.

:::

|  | WORK STEP | ADDITIONAL INFO / IMAGES |
| --- | --- | --- |
| 1. | In the top right corner of the web interface, click the username to open the user menu. | <img src="/img/manual/cell-f60b02982fd9.png" alt="Illustration for table on manual page 123" width="284" className="manual-figure" loading="lazy"/> |
| 2. | Select Reboot and confirm the request. |  |
| 3. | The instrument reboots and a new login is required. |  |
