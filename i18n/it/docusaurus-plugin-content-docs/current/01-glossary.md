| Termine | Spiegazione |
| --- | --- |
| ACC | Active Cell Count (conteggio delle cellule attive). La cartuccia ACC misura le cellule metabolicamente attive mediante un saggio enzimatico. ACC è il numero totale di cellule attive all’interno del gate ACC. |
| CBC | Coliform Cell Count (conteggio delle cellule coliformi). Numero di cellule coliformi contate nel campione. |
| Cartuccia | Contenitore ricaricabile dei reagenti necessari al funzionamento di BactoSense |
| EBC | E. coli Cell Count (conteggio delle cellule di E. coli). Numero di cellule di E. coli contate nel campione. |
| FCS | Flow Cytometry Standard (FCS) è uno standard di file per la lettura e la scrittura dei dati degli esperimenti di citometria a flusso. La specifica FCS è stata tradizionalmente sviluppata e mantenuta dall’International Society for Advancement of Cytometry (ISAC). In passato, FCS era l’unico formato di file ampiamente adottato nella citometria a flusso. |
| FL1 | Segnale di fluorescenza 1 (530 nm) |
| FL2 | Segnale di fluorescenza 2 (715 nm) |
| FSC | Diffusione in avanti, detta anche diffusione della luce a piccolo angolo. Un rilevatore misura la luce diffusa dai microrganismi e da altre particelle a piccoli angoli. |
| Gate | I gate sono strumenti per analizzare un sottoinsieme di punti dati nella citometria a flusso. |
| HNA | High Nucleic Acid (alto contenuto di acidi nucleici). Batteri con una quantità elevata di DNA che producono una forte emissione di fluorescenza. |
| HNAC | High Nucleic Acid Count. Numero di batteri HNA all’interno del gate TCC o ICC e al di sopra del limite HNA / LNA. |
| HNAP [%] | High Nucleic Acid Percentage. Percentuale di batteri HNA rispetto al conteggio cellulare. |
| ICC | Intact Cell Count (conteggio delle cellule integre). Numero totale di batteri integri all’interno del gate ICC. |
| LNA | Low Nucleic Acid (basso contenuto di acidi nucleici). Batteri con una quantità inferiore di DNA che producono un’emissione di fluorescenza più debole rispetto ai batteri HNA. |
| LNAC | Low Nucleic Acid Count. Numero di batteri LNA all’interno del gate TCC o ICC al di sotto del limite HNA / LNA. |
| Dispositivo di campionamento manuale | Modulo di collegamento che consente il campionamento manuale con BactoSense Online. |
| NBC | Enterococcus Cell Count (conteggio delle cellule di Enterococcus). Numero di cellule di Enterococcus contate nel campione. |
| Dispositivo di campionamento in linea | Modulo di collegamento a una linea idrica che consente il campionamento in linea con BactoSense Online. |
| SSC | Diffusione laterale, detta anche diffusione della luce a grande angolo. Un rilevatore misura la luce diffusa dai microrganismi e da altre particelle a 90 gradi. |
| TCC | Total Cell Count (conteggio cellulare totale). Numero totale di batteri rilevati all’interno del gate TCC. |
