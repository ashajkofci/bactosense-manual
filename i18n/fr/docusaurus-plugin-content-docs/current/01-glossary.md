| Terme | Définition |
| --- | --- |
| ACC | Nombre de cellules actives. La cartouche ACC mesure les cellules métaboliquement actives au moyen d’un dosage enzymatique. ACC désigne le nombre total de cellules actives à l’intérieur de la fenêtre ACC. |
| CBC | Nombre de cellules coliformes. Nombre de cellules coliformes dénombrées dans l’échantillon. |
| Cartouche | Récipient rechargeable contenant les réactifs nécessaires au fonctionnement du<br/>BactoSense |
| EBC | Nombre de cellules E. coli. Nombre de cellules E. coli dénombrées dans l’échantillon. |
| FCS | Le format de fichier FCS (Flow Cytometry Standard) est une<br/>norme de lecture et d’écriture des données issues des<br/>expériences de cytométrie en flux. La spécification FCS est traditionnellement<br/>développée et maintenue par l’International Society for Advancement of<br/>Cytometry (ISAC). Le FCS a longtemps été le seul<br/>format de fichier largement adopté en cytométrie en flux. |
| FL1 | Signal de fluorescence 1 (530 nm) |
| FL2 | Signal de fluorescence 2 (715 nm) |
| FSC | Diffusion vers l’avant, également appelée diffusion de la lumière<br/>aux petits angles. Un détecteur mesure la lumière diffusée par<br/>les micro-organismes et les autres particules sous de petits angles. |
| Fenêtre | Les fenêtres sont des outils d’analyse d’un sous-ensemble de points de données<br/>en cytométrie en flux. |
| HNA | Haut taux d’acide nucléique. Bactéries contenant une grande<br/>quantité d’ADN, qui émettent une forte fluorescence. |
| HNAC | Nombre de bactéries à haut taux d’acide nucléique. Nombre de bactéries HNA à<br/>l’intérieur de la fenêtre TCC ou ICC et au-dessus de la limite HNA<br/>/ LNA. |
| HNAP [%] | Pourcentage de bactéries à haut taux<br/>d’acide nucléique. Pourcentage de bactéries HNA par rapport au nombre de cellules. |
| ICC | Nombre de cellules intactes. Nombre total de bactéries intactes à l’intérieur de<br/>la fenêtre ICC. |
| LNA | Faible taux d’acide nucléique. Bactéries contenant moins d’ADN,<br/>qui émettent une fluorescence plus faible que les bactéries<br/>HNA. |
| LNAC | Nombre de bactéries à faible taux d’acide nucléique. Nombre de bactéries LNA à l’intérieur<br/>de la fenêtre TCC ou ICC et en dessous de la limite HNA / LNA. |
| Dispositif d’échantillonnage manuel | Module de connexion permettant l’échantillonnage manuel avec<br/>le BactoSense Online. |
| NBC | Nombre de cellules Enterococcus. Nombre de cellules Enterococcus dénombrées dans l’échantillon. |
| Dispositif d’échantillonnage en ligne | Module de connexion à une conduite d’eau permettant l’échantillonnage<br/>en ligne avec le BactoSense Online. |
| SSC | Diffusion latérale, également appelée diffusion de la lumière aux grands angles.<br/>Un détecteur mesure la lumière diffusée par<br/>les micro-organismes et les autres particules à 90 degrés. |
| TCC | Nombre total de cellules. Nombre total de bactéries détectées à l’intérieur de<br/>la fenêtre TCC. |
