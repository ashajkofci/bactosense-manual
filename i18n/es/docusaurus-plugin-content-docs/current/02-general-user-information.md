## 2.1 Acerca de este manual de usuario {#section-2-1}

Este manual de usuario proporciona información útil sobre todo el ciclo de vida de BactoSense y sus dispositivos periféricos. Antes de poner en servicio y utilizar el instrumento, debe familiarizarse por completo con el manual de usuario.

El manual de usuario está destinado a todas las personas responsables del funcionamiento y mantenimiento del instrumento. Este documento forma parte del producto. Debe guardarse en un lugar seguro y estar siempre a disposición del usuario.

Puede solicitar la versión más reciente de este documento al representante de bNovate en su país. Encontrará una lista de todos los representantes de bNovate en nuestro sitio web: www.bnovate.com/distribution-partners.

## 2.2 Conformidad y normas aplicadas {#section-2-2}

BactoSense se ha diseñado y fabricado para cumplir o superar las normas reconocidas del sector, a fin de garantizar la seguridad, las prestaciones y la fiabilidad del producto.

<img src="/img/manual/asset-5b67a16d691d.png" alt="Marcado de conformidad CE" width="72" loading="lazy" />

El dispositivo cumple todos los requisitos aplicables para llevar el marcado CE. Para obtener más información, consulte la declaración de conformidad independiente.

<img src="/img/manual/asset-fdc39c428b7f.png" alt="Marcado de conformidad UKCA" width="72" loading="lazy" />

El dispositivo cumple todos los requisitos aplicables para llevar el marcado UKCA. Para obtener más información, consulte la declaración de conformidad independiente.

Este aparato digital de clase B cumple todos los requisitos del reglamento canadiense sobre equipos que producen interferencias (CAN ICES-001 (B) / NMB-001 (B)).

Este dispositivo cumple la parte 15 de las normas de la FCC. Su funcionamiento está sujeto a las dos condiciones siguientes: (1) este dispositivo no debe causar interferencias perjudiciales y (2) este dispositivo debe aceptar cualquier interferencia recibida, incluidas las que puedan provocar un funcionamiento no deseado.

Este dispositivo está totalmente protegido contra la entrada de polvo y contra los chorros de agua a baja presión procedentes de cualquier dirección (IP65).

Este dispositivo cumple FCC, UL/CAN/CSA-C22.2/IEC 61010-1 y JIS C 1010-1. Para obtener más información, consulte el informe de ensayo CB (https://certificates.iecee.org: CH-12116).

## 2.5 Uso previsto de BactoSense {#section-2-5}

:::info[Uso previsto]

El uso previsto de BactoSense es medir la concentración de microorganismos en el agua. En particular, el instrumento se ha desarrollado para contar y caracterizar poblaciones bacterianas.

El instrumento debe ser utilizado por personal técnico cualificado que haya leído y comprendido el contenido del manual de usuario.

:::

## 2.6 Restricciones de uso {#section-2-6}

:::danger[Atmósferas explosivas]

El funcionamiento en zonas con atmósfera explosiva puede causar explosiones que provoquen lesiones o la muerte de las personas que se encuentren en las proximidades.

- No se permite utilizar el instrumento en zonas o salas con riesgo de explosión.
- No se permite utilizar el instrumento con muestras de sustancias explosivas.

:::
