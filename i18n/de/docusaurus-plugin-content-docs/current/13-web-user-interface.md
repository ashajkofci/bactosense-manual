## 13.1 Allgemeine Informationen {#section-13-1}

- Die Web-Oberfläche erlaubt es dem Benutzer, Ergebnisse und weitere Daten über einen Remotecomputer zu durchsuchen und zu exportieren sowie den Gerätestatus (aktive Prozesse, Kartuschenfüllstand, Alarme usw.) zu überwachen.
- Der BactoSense muss mit dem selben Netz verbunden sein wie der Computer, der auf die Web-Oberfläche zugreifen soll.
- Die Web-Oberfläche kann mit jedem Browser auf Computern oder Mobilgeräten angesehen werden.
- Sorgen Sie für Daten- und Netzwerksicherheit mit allen üblichen Maßnahmen.

## 13.5 Herunterladen einer Zip-Datei mit mehreren Ergebnissen {#section-13-5}

Die Ergebnisse mehrerer Messungen können als Zip-Datei heruntergeladen werden. Diese Zip enthält die FCS-Datei und die zusammenfassenden Darstellungen jeder Messung.

|  | ARBEITSSCHRITT | ZUSÄTZLICHE INFORMATIONEN / ABBILDUNGEN |
| --- | --- | --- |
| 1. | Wählen Sie in der Web-Oberfläche im Navigationsfeld links die Seite Ergebnisse. |  |
| 2. | Suchen Sie die Ergebnisse für den gewünschten Modus: Ergebnisse des Online-Modus oder des manuellen Modus. |  |
| 3. | Wählen Sie den gewünschten Datumsbereich und klicken Sie Zip herunterladen. Es erscheint oben im Browser ein Fortschrittsbalken, bis der Download des Zip beginnt. | <img src="/img/manual/cell-836f089084c0.png" alt="Abbildung zur Tabelle auf Handbuchseite 121" width="282" className="manual-figure" loading="lazy"/> |
| 4. | Warten Sie, bis der Download abgeschlossen ist. |  |

## 13.6 Alle Ergebnisse als CSV, XLSX oder PDF herunterladen {#section-13-6}

Die Liste aller Ergebnisse kann über die Web-Oberfläche in den Formaten Excel XLSX, CSV und PDF heruntergeladen werden. Die Ergebnisse des Online-Modus (Auto) sind von denen des manuellen Modus abgetrennt.

|  | ARBEITSSCHRITT | ZUSÄTZLICHE INFORMATIONEN / ABBILDUNGEN |
| --- | --- | --- |
| 1. | Wählen Sie in der Web-Oberfläche im Navigationsfeld links die Seite Ergebnisse. |  |
| 2. | Suchen Sie unterhalb des Abschnitts PLOT den Abschnitt ERGEBNISSE HERUNTERLADEN. |  |
| 3. | Klicken Sie auf die gewünschte Datei (xlsx, csv or PDF), um den Download zu beginnen. | <img src="/img/manual/cell-9979275487c3.png" alt="Abbildung zur Tabelle auf Handbuchseite 121" width="282" className="manual-figure" loading="lazy"/> |
| 4. | Warten Sie, bis der Download abgeschlossen ist. |  |

## 13.7 Animieren der Entwicklung von Punktdiagrammen {#section-13-7}

Die Web-Oberfläche kann Punktdiagramme aus dem Online-Modus (Auto) animieren, um den Verlauf der Messung darzustellen. Diese Funktion zeigt Standbilder in schneller Abfolge. Die Animation kann mit der Taste GIF herunterladen exportiert werden.

|  | ARBEITSSCHRITT | ZUSÄTZLICHE INFORMATIONEN / ABBILDUNGEN |
| --- | --- | --- |
| 1. | Wählen Sie in der Web-Oberfläche im Navigationsfeld links die Seite Plots. | <img src="/img/manual/cell-0615055418e0.png" alt="Abbildung zur Tabelle auf Handbuchseite 122" width="283" className="manual-figure" loading="lazy"/> |
| 2. | Verwenden Sie die Pfeile oder den Schieberegler, um den Regler auf dem gewünschten Datumsbereich zu platzieren. | <img src="/img/manual/cell-fec791f8e8fd.png" alt="Abbildung zur Tabelle auf Handbuchseite 122" width="283" className="manual-figure" loading="lazy"/> |
| 3. | Drücken Sie die Play-Taste, um die Animation zu starten. | <img src="/img/manual/cell-fb7fd241751c.png" alt="Abbildung zur Tabelle auf Handbuchseite 122" width="283" className="manual-figure" loading="lazy"/> |
| 4. | Passen Sie die Animationsgeschwindigkeit mittels des Feldes Animationsgeschwindigkeit an, falls erforderlich. |  |
| 5. | Die Animation kann als GIF-Datei heruntergeladen werden, wenn Sie die Taste GIF herunterladen drücken. |  |

## 13.10 Neustart aus der Web-Oberfläche {#section-13-10}

Der BactoSense kann mittels folgender Schritte über die Web-Oberfläche neugestartet werden.

:::info[Einschalten aus der Ferne nicht verfügbar]

Das Gerät kann nicht aus der Ferne eingeschaltet werden.

:::

|  | ARBEITSSCHRITT | ZUSÄTZLICHE INFORMATIONEN / ABBILDUNGEN |
| --- | --- | --- |
| 1. | Klicken Sie in der oberen rechten Ecke der Web-Oberfläche auf den Benutzernamen, um das Benutzermenü zu öffnen. | <img src="/img/manual/cell-f60b02982fd9.png" alt="Abbildung zur Tabelle auf Handbuchseite 123" width="284" className="manual-figure" loading="lazy"/> |
| 2. | Wählen Sie Neustart und bestätigen Sie die folgende Abfrage. |  |
| 3. | Das Gerät startet neu und es ist ein neuer Login erforderlich. |  |
