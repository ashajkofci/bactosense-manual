## 17.1 Lagerung {#section-17-1}

### 17.1.1 Lagerung des BactoSense {#section-17-1-1}

Vorbereitungen

|  | ARBEITSSCHRITT |
| --- | --- |
| 1. | Stellen Sie sicher, dass das manuelle Probenahmegerät eingesetzt ist |
| 2. | Führen Sie eine Probenahmegerätereinigung mit Washstation durch, wie unter [Manuelles Probenahmegerät mit Washstation reinigen](15-maintenance.md#section-15-2-2) beschrieben. Ist keine Washstation verfügbar, folgen Sie den Schritten unter [Manuelles Probenahmegerät mittels Basisreinigung reinigen](15-maintenance.md#section-15-2-3). |
| 3. | Lassen Sie einen leeren Schlauch oder eine leere Washstation an dem manuellen Probenahmegerät angebracht. |
| 4. | Folgen Sie der unter [Entfernen einer Kartusche](08-general-operations-and-configurations.md#section-8-9-5) beschriebenen Kartuschenentnahmeprozedur, um die Kartusche sicher zu entfernen. Hinweis: Die Entnahme einer Kartusche ist nicht erforderlich, wenn die Lagerungsbedingungen der Kartusche ebenfalls erfüllt sind. |
| 5. | BactoSense ausschalten. |
| 6. | Trennen Sie das Netzteil von der Spannungsquelle, bevor Sie das Netzteil vom BactoSense trennen. |
| 7. | Stellen Sie sicher, dass die USB-, Ethernet- und Spannungsanschlüsse mit den vorgesehenen Deckeln bedeckt sind. |
| 8. | Packen Sie den BactoSense mit angebrachtem manuellem Probenahmegerät in seinen Standardkarton mit Schaumstoffeinlagen. Alternativ verwenden Sie den Transportbehälter |

**Lagerung**

Lagern Sie den BactoSense unter folgenden Bedingungen:

- Temperatur zwischen 15°C und 25°C (59°F – 77°F)
- Relative Luftfeuchtigkeit zwischen 10% und 70%
- Umgebung vibrationsfrei, nicht ätzend, dunkel und sauber

**Wiederinbetriebnahme**

Befolgen Sie nach der Lagerung die allgemeinen Installationsanweisungen unter [Installation](05-installation.md).

:::info[Nach Lagerung validieren]

Wurde der BactoSense länger als einen Monat gelagert, führen Sie vor der ersten Messung eine Gerätevalidierung mit dem Validierungskit durch, um die ordnungsgemäße Funktion sicherzustellen.

:::

### 17.1.2 Lagerung der Probenahmegeräte {#section-17-1-2}

Hinweis: Es sollte stets ein Probenahmegerät am BactoSense installiert sein. Die folgenden Schritte beschreiben das Lagern zusätzlicher Probenahmegeräte, sofern vorhanden.

Vorbereitungen

|  | ARBEITSSCHRITT | ZUSÄTZLICHE INFORMATIONEN / ABBILDUNGEN |
| --- | --- | --- |
| 1. | Entfernen Sie das aktuell installierte Probenahmegerät entsprechend den Anweisungen unter [Entfernen des manuellen Probenahmegeräts](08-general-operations-and-configurations.md#section-8-10-2) bzw. [Entfernen des Online-Probenahmegeräts](08-general-operations-and-configurations.md#section-8-10-1). | Tragen Sie während des Verfahrens Handschuhe, um das Probenahmegerät nicht zu verunreinigen. Zeigen die Schläuche des Online-Probenahmegeräts Anzeichen von Verunreinigungen oder Schäden, verwenden Sie sie nicht erneut, sondern entsorgen Sie sie. |
| 2. | Decken Sie das gereinigte entnommene Probenahmegerät mit dem Schraubdeckel ab, wenn vorhanden. | ![Abbildung zur Tabelle auf Handbuchseite 153](/img/manual/cell-8fdb2d0e492f.png "width=132 class=manual-figure") |
| 3. | Packen Sie das abgedeckte Probenahmegerät in einen sauberen, trockenen Plastikbeutel. |  |

**Lagerung**

Lagern Sie das Probenahmegerät unter folgenden Bedingungen:

- Temperatur zwischen 5°C und 40°C (41°F – 104°F)
- Relative Luftfeuchtigkeit zwischen 10% und 70%
- Umgebung vibrationsfrei, nicht ätzend, dunkel und sauber

**Wiederinbetriebnahme**

Befolgen Sie nach der Lagerung die allgemeinen Installationsanweisungen unter [Installation des manuellen Probenahmegeräts](05-installation.md#section-5-4) bzw. [Installation des Online-Probenahmegeräts](05-installation.md#section-5-5).

### 17.1.3 Lagerung der Kartusche {#section-17-1-3}

:::warning[Vor austretenden Chemikalien schützen]

Tragen Sie Schutzhandschuhe und -brille. Auslaufende Chemikalien können Hautreizungen, Augenschäden und sonstige Gesundheitsschäden hervorrufen. Stellen Sie sicher, dass die fluidischen Anschlüsse der Kartusche fest mittels passender Verschlüsse verschlossen sind.

:::

:::info[Ablaufdatum der Kartusche prüfen]

Überprüfen Sie das Ablaufdatum der Kartusche. Das Ablaufdatum ist auf dem Kartuschengriff im Format Tag/Monat/Jahr aufgedruckt oder kann auf der Benutzeroberfläche des Geräts unter Startbildschirm → Einstellungen → Informationen gefunden werden.

:::

Vorbereitungen

|  | ARBEITSSCHRITT |
| --- | --- |
| 1. | Tragen Sie Schutzhandschuhe und -brille. |
| 2. | Folgen Sie der unter [Entfernen einer Kartusche](08-general-operations-and-configurations.md#section-8-9-5) beschriebenen Kartuschenentnahmeprozedur, um die Kartusche sicher aus dem BactoSense zu entfernen. |
| 3. | Stellen Sie sicher, dass die fluidischen Anschlüsse der Kartusche fest mittels passender Verschlüsse verschlossen sind. |
| 4. | Packen Sie die Kartusche in ihren Standardkarton mit Schaumstoffeinlagen. |

**Lagerung**

Lagern Sie die Kartusche unter folgenden Bedingungen:

- Temperatur zwischen 15°C und 25°C (59°F – 77°F), idealerweise 15°C
- Relative Luftfeuchtigkeit zwischen 20% und 60%
- Umgebung vibrationsfrei, nicht ätzend, dunkel und sauber

**Wiederinbetriebnahme**

Befolgen Sie nach der Lagerung die allgemeinen Installationsanweisungen unter [Einsetzen einer Kartusche](08-general-operations-and-configurations.md#section-8-9-6).

### 17.2.2 Transport der Kartusche {#section-17-2-2}

Vorbereitungen

|  | ARBEITSSCHRITT |
| --- | --- |
| 1. | Tragen Sie Schutzhandschuhe und -brille |
| 2. | Folgen Sie der unter [Entfernen einer Kartusche](08-general-operations-and-configurations.md#section-8-9-5) beschriebenen Kartuschenentnahmeprozedur, um die Kartusche sicher zu entfernen. |
| 3. | Stellen Sie sicher, dass die fluidischen Anschlüsse der Kartusche fest mittels passender Verschlüsse verschlossen sind. |
| 4. | Packen Sie die Kartusche in ihren Standardkarton mit Schaumstoffeinlagen oder verwenden Sie den Transportbehälter, sofern verfügbar. |

**Transport**

Transportieren Sie die Kartusche in ihrer normalen horizontalen Position. Es gelten die unter [Technische Daten](03-instrument-overview.md#section-3-2) beschriebenen Lagerbedingungen für Kartuschen.

**Wiederinbetriebnahme**

Befolgen Sie nach dem Transport die allgemeinen Installationsanweisungen unter [Einsetzen einer Kartusche](08-general-operations-and-configurations.md#section-8-9-6).

## 17.3 Rückgabe des BactoSense oder seines Zubehörs {#section-17-3}

Falls Sie den BactoSense oder Zubehörteile an bNovate oder einen Distributionspartner zurückgeben wollen, folgen Sie bitte den Anweisungen in diesem Abschnitt.

:::warning[Vor Rücksendung dekontaminieren]

Geben Sie keine kontaminierten Materialien zurück

Geräte, die in Kontakt mit gefährlichen Substanzen dürfen nicht undekontaminiert und ohne Dekontaminationszertifikat verschickt werden. Bitte wenden Sie sich an support@bnovate.com, um weitere Informationen zu erhalten.

:::

:::warning[Versandanweisungen befolgen]

Halten Sie sich an die Anweisungen zum Versand

bNovate ist nicht für empfangene Sendungen verantwortlich, die nicht unseren Versandkriterien entsprechen. Für die Reparatur wird in diesem Fall eine Gebühr erhoben. Bitte wenden Sie sich an support@bnovate.com, falls die Originalverpackung nicht mehr vorhanden ist oder Sie Hilfe beim Verpacken benötigen.

:::

| 6. | BactoSense ausschalten. |
| 7. | Trennen Sie das Netzteil von der Spannungsquelle, bevor Sie das Netzteil vom BactoSense trennen. |

Vorbereitungen

|  | ARBEITSSCHRITT |
| --- | --- |
