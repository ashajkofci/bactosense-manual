| Begriff | Erklärung |
| --- | --- |
| ACC | Anzahl aktiver Zellen (Active Cell Count). Die ACC-Kartusche erfasst metabolisch aktive Zellen mittels eines enzymatischen Tests. ACC ist die Gesamtzahl aktiver Zellen innerhalb des ACC-Gates. |
| CBC | Anzahl coliformer Zellen (Coliform Cell Count). Anzahl der in der Probe gezählten coliformen Zellen. |
| Kartusche | Nachfüllbarer Behälter mit den für den Betrieb des BactoSense erforderlichen Reagenzien. |
| EBC | Anzahl der E.-coli-Zellen (E. coli Cell Count). Anzahl der in der Probe gezählten E.-coli-Zellen. |
| FCS | Flow Cytometry Standard (FCS) ist ein Dateistandard zum Lesen und Schreiben von Daten aus Durchflusszytometrie-Experimenten. Die FCS-Spezifikation wurde traditionell von der International Society for Advancement of Cytometry (ISAC) entwickelt und gepflegt. FCS war früher das einzige weit verbreitete Dateiformat in der Durchflusszytometrie. |
| FL1 | Fluoreszenzsignal 1 (530 nm) |
| FL2 | Fluoreszenzsignal 2 (715 nm) |
| FSC | Vorwärtsstreuung, auch als Kleinwinkel-Lichtstreuung bezeichnet. Ein Detektor misst das von Mikroorganismen und anderen Partikeln in kleinen Winkeln gestreute Licht. |
| Gate | Gates sind Werkzeuge zur Analyse einer Teilmenge von Datenpunkten in der Durchflusszytometrie. |
| HNA | Hoher Nukleinsäuregehalt (High Nucleic Acid). Bakterien mit einer großen DNA-Menge, die eine starke Fluoreszenzemission erzeugen. |
| HNAC | Anzahl der Bakterien mit hohem Nukleinsäuregehalt (High Nucleic Acid Count). Anzahl der HNA-Bakterien innerhalb des TCC- oder ICC-Gates und oberhalb der HNA/LNA-Grenze. |
| HNAP [%] | Prozentanteil der Bakterien mit hohem Nukleinsäuregehalt (High Nucleic Acid Percentage). Anteil der HNA-Bakterien an der Zellzahl in Prozent. |
| ICC | Intaktzellzahl (Intact Cell Count). Gesamtzahl intakter Bakterien innerhalb des ICC-Gates. |
| LNA | Niedriger Nukleinsäuregehalt (Low Nucleic Acid). Bakterien mit geringerer DNA-Menge, die eine schwächere Fluoreszenzemission als HNA-Bakterien erzeugen. |
| LNAC | Anzahl der Bakterien mit niedrigem Nukleinsäuregehalt (Low Nucleic Acid Count). Anzahl der LNA-Bakterien innerhalb des TCC- oder ICC-Gates unterhalb der HNA/LNA-Grenze. |
| Manuelles Probenahmegerät | Anschlussmodul für die manuelle Probenahme mit dem BactoSense Online. |
| NBC | Enterokokken-Zellzahl (Enterococcus Cell Count). Anzahl der in der Probe gezählten Enterokokken. |
| Online-Probenahmegerät | Anschlussmodul für eine Wasserleitung zur Online-Probenahme mit dem BactoSense Online. |
| SSC | Seitenstreuung, auch als Großwinkel-Lichtstreuung bezeichnet. Ein Detektor misst das von Mikroorganismen und anderen Partikeln im Winkel von 90 Grad gestreute Licht. |
| TCC | Gesamtzellzahl (Total Cell Count). Gesamtzahl der innerhalb des TCC-Gates erkannten Bakterien. |
