## 1.1 About this instruction manual {#section-1-1}

This instruction manual provides the user with helpful information about the entire life cycle of the BactoSwitch. Before commissioning and using the BactoSwitch, the user should be completely familiar with this instruction manual. As the BactoSwitch is an accessory of the BactoSense, the user should also be familiar with the [BactoSense user manual](/bactosense/). All bNovate manuals can be found online at [www.bnovate.com/user-manuals](https://www.bnovate.com/user-manuals).

This instruction manual is intended for all persons who are responsible for the operation and maintenance of the instrument. This document is part of the product. It should be stored in a safe place and always be available to the user.

## 1.5 Intended use of the BactoSwitch {#section-1-5}

:::info[Intended use]

The BactoSwitch is an accessory for the BactoSense CORE or BactoSense SMART, serial number 910500 onwards, software version 3.1.0 onwards.

The intended use of the BactoSwitch is to sequentially route water from each of its four inlets to the attached BactoSense instrument, to the integrated flowmeter and finally to the drain.

The BactoSwitch (and BactoSense) must be operated by trained technical personnel who have read and understood the content of both user manuals.

:::

## 1.6 Usage restrictions {#section-1-6}

:::explosion[Explosive environments]

Operation in explosive areas can cause explosions, which can lead to the injury or death of persons in the vicinity.

- It is not permitted to operate the instrument in explosion hazardous areas or rooms.
- It is not permitted to use the instrument with explosive sample substances.

:::
