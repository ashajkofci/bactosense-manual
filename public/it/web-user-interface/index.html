13. Interfaccia utente web

13.1 Informazioni generali​

  • L’interfaccia web consente di consultare ed esportare risultati e altri dati da un computer remoto e di monitorare lo stato dello strumento (processo attivo, livello della cartuccia, avvisi, ecc.).
  • BactoSense deve essere collegato alla stessa rete del computer che accede all’interfaccia web.
  • L’interfaccia web può essere caricata in qualsiasi browser su computer desktop o dispositivi mobili.
  • Adottare tutte le misure consuete per la sicurezza dei dati e della rete.

13.2 Collegamento all’interfaccia utente web​

OPERAZIONEINFORMAZIONI AGGIUNTIVE / IMMAGINI
1.Collegare BactoSense via Ethernet a una rete sicura (ad esempio LAN). Collegare il proprio dispositivo (ad esempio computer o tablet) alla stessa rete.
2.Accedere al menu Home dell’interfaccia di BactoSense. Premere System info.
3.Recuperare l’indirizzo IP di BactoSense mostrato nella pagina System info.
4.Aprire un browser web sul proprio dispositivo.
5.Inserire l’indirizzo IP di BactoSense nella barra degli indirizzi e premere Invio.
6.Nella pagina di accesso, utilizzare lo stesso nome utente e la stessa password di BactoSense e premere Login.

13.4 Download di un file FCS​

OPERAZIONEINFORMAZIONI AGGIUNTIVE / IMMAGINI
1.Nell’interfaccia web, selezionare la pagina Results nel pannello di navigazione a sinistra.
2.Accedere al risultato da esportare.
3.Fare clic sul collegamento fcs (posizione X).
4.Attendere il completamento del download.

13.5 Download di un file ZIP con più risultati​

I risultati di più misurazioni possono essere scaricati come file ZIP. L’archivio comprende il file FCS e i grafici riepilogativi di ogni misurazione.

OPERAZIONEINFORMAZIONI AGGIUNTIVE / IMMAGINI
1.Nell’interfaccia web, selezionare la pagina Results nel pannello di navigazione a sinistra.
2.Individuare i risultati della modalità desiderata: risultati Auto o Manual.
3.Selezionare l’intervallo di date desiderato e fare clic su Download ZIP. Una barra di avanzamento viene visualizzata nella parte superiore del browser fino all’avvio del download.
4.Attendere il completamento del download.

13.6 Download di tutti i risultati in formato CSV, XLSX o PDF​

L’elenco di tutti i risultati può essere scaricato dall’interfaccia web in formato Excel XLSX, CSV o PDF. I risultati della modalità Auto sono separati da quelli della modalità Manual.

OPERAZIONEINFORMAZIONI AGGIUNTIVE / IMMAGINI
1.Nell’interfaccia web, selezionare la pagina Results nel pannello di navigazione a sinistra.
2.Individuare la sezione DOWNLOAD RESULTS, appena sotto la sezione PLOT superiore.
3.Fare clic sul file desiderato (xlsx, csv o PDF) per avviare il download.
4.Attendere il completamento del download.

13.7 Animazione dell’evoluzione dei diagrammi a punti​

L’interfaccia web può animare i diagrammi a punti della modalità Auto per aiutare a visualizzare l’evoluzione delle misurazioni. Questa funzione mostra immagini statiche in rapida successione; l’animazione può quindi essere esportata solo con un software di registrazione dello schermo.

OPERAZIONEINFORMAZIONI AGGIUNTIVE / IMMAGINI
1.Nell’interfaccia web, selezionare la pagina Dotplots nel pannello di navigazione a sinistra.
2.Utilizzare le frecce precedente e successiva o il cursore per centrare quest’ultimo sull’intervallo di date desiderato.
3.Premere Play per avviare l’animazione.
4.Se necessario, regolare la velocità tramite l’apposito campo.
5.L’animazione può essere scaricata come file GIF premendo Download GIF.

13.8 Modifica dell’intervallo di misurazione​

Se lo strumento è in modalità Auto, l’intervallo di misurazione può essere modificato dall’interfaccia web.

OPERAZIONEINFORMAZIONI AGGIUNTIVE / IMMAGINI
1.Nell’interfaccia web, selezionare la pagina Settings nel pannello di navigazione a sinistra.
2.Modificare la durata dell’intervallo di misurazione.
3.Fare clic su Save per confermare.

13.9 Acquisizione di schermate dell’interfaccia grafica​

Acquisire schermate dell’interfaccia grafica di BactoSense dall’interfaccia web:

OPERAZIONEINFORMAZIONI AGGIUNTIVE / IMMAGINI
1.Nell’interfaccia web, selezionare la pagina System info nel pannello di navigazione a sinistra.
2.Premere Get screenshot nella parte inferiore della pagina.
3.La schermata viene visualizzata sotto.

13.10 Riavvio dall’interfaccia utente web​

BactoSense può essere riavviato dall’interfaccia web secondo la procedura seguente.

L’accensione remota non è disponibile

Lo strumento non può essere acceso da remoto.

OPERAZIONEINFORMAZIONI AGGIUNTIVE / IMMAGINI
1.Nell’angolo superiore destro dell’interfaccia web, fare clic sul nome utente per visualizzare l’elenco delle opzioni.
2.Selezionare Reboot e confermare la richiesta di conferma.
3.Lo strumento si riavvia ed è necessario effettuare nuovamente l’accesso.
